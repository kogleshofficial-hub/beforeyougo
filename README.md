# BeforeYouGo

Know what you need before you go.

BeforeYouGo turns official service instructions into practical pre-visit checklists: what to prepare, what to verify, and where the authoritative source lives.

## MVP

- Searchable service guides
- Country/category filters
- Interactive browser-only checklists
- Official source links and verification dates
- Responsive, accessible UI
- SEO metadata, sitemap.xml and robots.txt
- No account or database required for the MVP

## Principles

BeforeYouGo never invents requirements or presents community guesses as official facts. Each guide points users to the authoritative source and reminds them to verify current requirements before travelling.
